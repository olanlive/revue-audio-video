RTMP Server Source 0.1.0 (plugin OBS)

Plugin libre (GPL-2.0) qui met un serveur RTMP dans OBS : caméra, téléphone ou autre PC y diffusent et arrivent comme une source normale, sans nginx. Plusieurs clés sur un port, reconnexion auto, H.264/HEVC/AV1. Écrit avec une IA ; 0.1.0 (22 oct), macOS seulement.
