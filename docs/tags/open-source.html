FFmpeg 9.0.2 « Lei »

Le moteur d’encodage derrière Blender, OBS et Shotcut passe en 9.0 : filtres IA sur GPU via ONNX Runtime, vidéo 360° en Vulkan, WebP animé, ProRes RAW accéléré sur Mac. La 9.0.2 (18 sept) ajoute des correctifs de sécurité.

Trouvé via : Web — ffmpeg.org (Download + Changelog n9.0.2)

Audacity 4.0.1

Audacity 4 reconstruit son interface sur Qt : clips sélectionnables et groupables, espaces de travail, ASIO sous Windows. La 4.0.1 (30 sept) corrige les bugs de jeunesse et ajoute l’export d’une piste ou d’une région par fichier, plus une version portable Windows.

Trouvé via : Release GitHub — audacity/audacity 4.0.1

OBS Studio 33.0 bêta 6

OBS 33 (bêta 6, 3 oct) refond le chargement des plugins, avec un nouveau dossier pour les plugins tiers à anticiper côté IT. Au programme aussi : moteur des sources navigateur mis à jour (CEF 150), magnétisme des sources revu et NVENC sur Arm64.

Trouvé via : Release GitHub — obsproject/obs-studio 33.0.0-beta6

Shotcut 26.9.27 (+ MLT 7.42.0)

Le monteur libre ajoute le ducking audio automatique, un volume et un vumètre par piste, et un « Adjustment Clip » qui filtre toutes les pistes en dessous. Passage à FFmpeg 9.0 et failles de téléchargement corrigées : mise à jour recommandée.

Trouvé via : Web — shotcut.org (blog 26.9.27)

Aegisub 3.5.0

L’éditeur de sous-titres ASS de référence sort la 3.5.0 (4 oct) : zoom et panoramique dans la vidéo, High-DPI bien meilleur, builds Apple Silicon natives. Elle corrige une faille où un fichier piégé pouvait exécuter du code : mise à jour à faire.

Shutter Encoder 20.4

Toute la puissance de FFmpeg sans terminal : proxys, ProRes/DNx, découpe sans réencodage. La 20.4 (28 sept) ajoute un filtre de grain film, la normalisation de crête et le retrait des images dupliquées pour tous les codecs.

Image Sequence to MP4 (add-on Blender) 2.0.0

Vos rendus PNG/EXR deviennent un MP4 (H.264, H.265 ou AV1) en un clic, en tâche de fond, sans bloquer Blender. La 2.0.0 (2 oct) détecte les frames manquantes, respecte la gestion des couleurs et propose des presets Web, 720p et 9:16.

Trouvé via : Web — extensions.blender.org (historique des versions)

slatefree 1.2.0

Outil Rust en ligne de commande qui synchronise des centaines de clips multi-caméras sans clap ni timecode, calés sur l’audio continu d’un enregistreur. Sortie : timeline FCP 7 XML pour Resolve et CSV de contrôle par clip. Repo créé le 6 oct, déjà en v1.2.0.

Trouvé via : Fil X — @VFXDESK
