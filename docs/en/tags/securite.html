LosslessCut 3.70.1

The free tool (GPL-2.0) for cutting and remuxing video and audio without re-encoding reaches 3.70 (Oct 19): bundled FFmpeg 8.1 (fixes a CVE), a much richer metadata editor, more accurate MKV/WebM cuts and a light/dark theme. On Windows, get 3.70.1.

MediaMTX 1.21.2

Ready-to-use live stream server and proxy (SRT, WebRTC, RTSP, RTMP, LL-HLS, Media-over-QUIC) that publishes, records and plays back audio and video. 1.21.2 (Oct 8) closes open access to the playback server and filters non-standard SEI from some cameras.

Shotcut 26.9.27 (+ MLT 7.42.0)

The free editor adds automatic audio ducking, per-track volume and VU meter, and an “Adjustment Clip” that filters every track below it. Moves to FFmpeg 9.0 and fixes download vulnerabilities: update recommended.

Aegisub 3.5.0

The reference ASS subtitle editor releases 3.5.0 (Oct 4): zoom and pan in the video, much better High-DPI, native Apple Silicon builds. It fixes a flaw where a crafted file could execute code: update now.
