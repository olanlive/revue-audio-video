Sonix Studio 0.9.167

New native Linux DAW in Rust (GPL-3.0), FL Studio-style: channel rack, piano roll, mixer with buses, VST3/CLAP/VST2 hosting, in one binary (.deb, .rpm, AppImage). An optional AI assistant, using your own API key, lays down a beat from a sentence.

RTMP Server Source 0.1.0 (plugin OBS)

Open-source (GPL-2.0) plugin that puts an RTMP server inside OBS: cameras, phones or other PCs stream to it and show up as a normal source, no nginx. Several keys on one port, auto-reconnect, H.264/HEVC/AV1. AI-written; 0.1.0 (Oct 22), macOS only.

Found via: Mastodon — @davvore33@livellosegreto.it

SQ8L 1.0.0 beta 3 (64-bit port)

A 64-bit port of SQ8L, the free Ensoniq SQ-80 emulation long stuck on 32-bit Windows: sample-identical sound, old projects and banks load unchanged, as VST2/VST3/AU/CLAP plus LV2 on Linux. Port code under MIT, still in beta.

Morphoice synth recreating the Commodore 64 SID chip, bit-accurately modelled at the original clock (6581 and 8580): solo, chiptune arpeggio and 16-voice poly modes, Juno-style chorus. Free pay-what-you-want beta (Oct 16); the final version may be paid.
